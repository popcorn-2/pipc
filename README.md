# Popcorn2 IPC Protocol (PIP) Compiler

This is the compiler used to parse PIP source files (`.pip`), and generate either PIP binaries (`.pipb`) for installation to a Popcorn2 distribution, or language level bindings for use in writing executables that make direct use of PIP.

The PIP sources for all core protocols can be found in [popcorn-2/core-protocols](github.com/popcorn-2/core-protocols).
